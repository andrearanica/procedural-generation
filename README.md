# Procedural Terrain Generation in OpenGL

This repository contains the source code for the University of Milan-Bicocca's computer graphics project.

The goal is to implement procedural generation of random worlds, in which is identified by a seed that allows you to modify the perlin noise function to obtain different worlds.
